# Singbox Rules

[English version below](#english-version)

Готовый набор правил маршрутизации для s-ui панели управления Sing-Box.

## Описание

Этот репозиторий содержит предварительно настроенные правила маршрутизации для Sing-Box, которые можно легко импортировать в s-ui панель одним кликом.

## Установка

### Способ 1: Импорт по URL (рекомендуется)

1. Откройте s-ui панель управления
2. Перейдите в раздел **Rules** (Правила)
3. Нажмите кнопку **Additional** (Дополнительно) между кнопками "Add Ruleset" и "Save"
4. Выберите **Importing rules** (Импорт правил)
5. Перейдите на вкладку **By URL**
6. Вставьте следующую ссылку:
   ```
   https://raw.githubusercontent.com/Pushkinmazila2/singbox-rules/main/rules.json
   ```
7. Нажмите кнопку **загрузки** (Download)
8. При наличии конфликтов выберите:
   - **Слияние** - для объединения с существующими правилами
   - **Замена** - для полной замены текущих правил

### Способ 2: Массовый импорт наборов правил

1. В том же меню **Additional** выберите **Mass import of rulesets**
2. Следуйте инструкциям на экране

## Содержимое

Правила включают оптимизированную конфигурацию маршрутизации для:
- Блокировки рекламы
- Обхода блокировок
- Оптимизации трафика
- Правил для различных сервисов

## Обновление

Для обновления правил просто повторите процесс импорта по URL. Рекомендуется выбирать "Замена" для получения актуальной версии.

## URL для импорта

```
https://raw.githubusercontent.com/Pushkinmazila2/singbox-rules/main/rules.json
```

# English Version

Ready-to-use routing rules set for s-ui Sing-Box management panel.

## Description

This repository contains pre-configured routing rules for Sing-Box that can be easily imported into the s-ui panel with one click.

## Installation

### Method 1: Import by URL (recommended)

1. Open s-ui management panel
2. Navigate to **Rules** section
3. Click **Additional** button between "Add Ruleset" and "Save" buttons
4. Select **Importing rules**
5. Go to **By URL** tab
6. Paste the following link:
   ```
   https://raw.githubusercontent.com/Pushkinmazila2/singbox-rules/main/rules.json
   ```
7. Click the **Download** button
8. If conflicts occur, choose:
   - **Merge** - to combine with existing rules
   - **Replace** - to completely replace current rules

### Method 2: Mass import of rulesets

1. In the same **Additional** menu, select **Mass import of rulesets**
2. Follow the on-screen instructions

## Contents

Rules include optimized routing configuration for:
- Ad blocking
- Bypass restrictions
- Traffic optimization
- Rules for various services

## Updates

To update rules, simply repeat the URL import process. It's recommended to choose "Replace" to get the latest version.

## Import URL

```
https://raw.githubusercontent.com/Pushkinmazila2/singbox-rules/main/rules.json
```
